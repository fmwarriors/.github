# Contributing to FMWarriors

Thank you for your interest in contributing to the FMWarriors community. This document outlines the guidelines for contributing to any repository under the [fmwarriors](https://github.com/fmwarriors) organization.

## How to contribute

- **Report a bug**: Open an issue using the bug report template.
- **Suggest an improvement**: Open an issue using the feature request template.
- **Submit code or resources**: Fork the repository, make your changes, and open a pull request.

## Guidelines

- Keep contributions relevant to Claris / FileMaker development.
- Write clear commit messages and PR descriptions.
- Test your changes before submitting.
- Be respectful and constructive in all discussions.

## Language

The primary language of the community is Spanish. English contributions are equally welcome.

## Questions

If you have any questions, bring them up directly in the group or open a discussion in the relevant repository.
