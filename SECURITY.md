# Security Policy

## Supported versions

This section applies to any repositories under the [fmwarriors](https://github.com/fmwarriors) organization that ship deployable code or scripts.

| Version | Supported |
|---------|-----------|
| Latest  | Yes       |
| Older   | No        |

## Reporting a vulnerability

If you discover a security vulnerability in any FMWarriors project, please **do not open a public issue**.

Instead, report it privately by contacting the maintainers directly through the group. We will acknowledge the report as soon as possible and coordinate a fix before any public disclosure.

Please include:

- A description of the vulnerability.
- Steps to reproduce it.
- Any relevant environment details (FileMaker version, OS, etc.).
- Your suggested fix, if any.

We appreciate responsible disclosure.
